# 🏹 Seikhlas Archery Club

Selamat datang ke repositori rasmi **Seikhlas Archery**. Ini merupakan hab digital utama untuk segala aktiviti, pengumuman, dan sumber berkaitan kelab memanah kami.

## 🎯 Visi & Misi
Kami komited untuk melahirkan pemanah yang bukan sahaja mahir dalam teknik, tetapi juga tinggi dalam aspek disiplin, fokus mental, dan semangat kesukanan.

## 🚀 Aktiviti Utama
1. **Latihan Mingguan:** Fokus kepada teknik *stance*, *drawing*, dan *aiming*.
2. **Bengkel Penyelenggaraan Busur:** Belajar cara menjaga *recurve bow* dan *traditional bow*.
3. **Kejohanan Dalaman:** Pertandingan bulanan untuk menguji prestasi ahli.
4. **Persediaan MSSD/MSSN/Open:** Latihan intensif untuk wakil sekolah.
